# 🛍️ Walking Store - Katalog Produk React

Aplikasi E-Commerce Katalog Interaktif yang dibangun menggunakan React, Vite, Tailwind CSS, dan Framer Motion.

## 🚀 Fitur Utama
- **Intro Landing Page:** Animasi logo dan splash screen interaktif.
- **Dark Mode / Light Mode:** Pengaturan tema web yang seamless.
- **Filter & Pencarian:** Filter berdasarkan kategori, pencarian kata kunci, dan filter favorit.
- **Shopping Cart Drawer:** Fitur tambah produk ke keranjang belanja dengan kuantitas dan kalkulasi total harga dinamis.
- **Form Tambah Produk:** Fitur penambahan katalog produk secara langsung (dinamis & tersimpan di LocalStorage).
- **Notifikasi Toast:** Notifikasi bawaan yang interaktif saat melakukan aksi favorit/keranjang.

## 🛠️ Teknologi yang Digunakan
- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React Icons
