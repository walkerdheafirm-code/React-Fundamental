# 🛍️ Walking Store - Katalog Produk (UTS React Fundamental)

Aplikasi E-Commerce Katalog Produk Interaktif yang dibangun menggunakan React, Vite, Tailwind CSS, dan Framer Motion.

## 🌟 Fitur Utama
1. **Splash Screen / Intro Landing Page**: Tampilan awal interaktif dengan animasi logo dan transisi ke katalog utama.
2. **Katalog Produk Dinamis**: Menampilkan daftar produk dengan status badge (Best Seller, Diskon, Stok, dll.).
3. **Pencarian & Filter Kategori**: Pencarian real-time berdasarkan nama produk dan kategori.
4. **Wishlist / Favorit**: Pengguna dapat menandai produk favorit dan menampilkannya secara khusus.
5. **Shopping Cart Drawer**: Keranjang belanja interaktif dengan kalkulasi total harga dinamis dan kontrol kuantitas.
6. **Dark Mode & Light Mode**: Dukungan tema gelap/terang secara mulus.
7. **Form Tambah Produk (CRUD Create)**: Fitur menambahkan katalog produk baru secara dinamis (tersimpan di LocalStorage).
8. **Responsive & Accessible**: Tampilan pas untuk pengguna HP/Mobile maupun Laptop/Desktop.

## 🛠️ Teknologi & Library
- **React.js (Vite)**
- **Tailwind CSS** (Styling UI & Dark Mode)
- **Framer Motion** (Animasi & Transisi Modal/Page)
- **Lucide React** (Ikon UI Modern)
